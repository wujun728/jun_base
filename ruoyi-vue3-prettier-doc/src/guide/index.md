# 项目介绍

RuoYi-Vue3-Prettier 是一个基于 Vue3、Vite、JavaScript、Element-Plus 的现代化后台管理系统。它采用了最新的前端技术栈，提供了丰富的功能组件和最佳实践。

## 特性

- 🚀 基于 Vue3、Vite、JavaScript、Element-Plus 等最新技术栈
- 💪 内置权限管理、数据大屏、代码生成等企业级功能
- 🎨 采用 Element-Plus 组件库，界面优雅美观
- 🔒 完善的权限管理，支持细粒度控制
- 📦 开箱即用，提供详细的文档和示例

## 技术栈

- 核心框架：Vue 3
- 构建工具：Vite
- 开发语言：JavaScript
- UI 框架：Element Plus
- 状态管理：Pinia
- 路由管理：Vue Router
- HTTP 工具：Axios
- 代码规范：ESLint + Prettier
- 提交规范：Husky + Commitlint

## 项目结构

```
src                       # 源代码目录
├── api                  # API 接口
├── assets               # 静态资源文件
├── BaseComponent        # 基础组件
├── components           # 业务组件
├── directive            # 自定义指令
├── hooks                # 钩子函数
├── layout               # 布局组件
├── plugins              # 插件配置
├── router               # 路由配置
├── store                # 状态管理
├── utils                # 工具函数
├── views                # 页面视图
├── App.vue              # 根组件
└── main.js              # 入口文件
vite                     # Vite 配置目录
.editorconfig            # 编辑器配置
.env.development         # 开发环境配置
.env.production          # 生产环境配置
.gitignore              # Git 忽略配置
.prettierignore         # Prettier 忽略配置
.prettierrc             # Prettier 配置
index.html              # HTML 模板
jsconfig.json           # JavaScript 配置
package.json            # 项目依赖
pnpm-lock.yaml          # pnpm 依赖锁定文件
README.md               # 项目说明
vite.config.js          # Vite 配置文件
```
