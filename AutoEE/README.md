# AutoEE-快速开发平台：前端框架autoee-ui
## 平台简介
- 基于 vue3 + CompositionAPI + vite + ant-design-vue3 实现的管理平台前端框架。
- 使用各组件的最新版本，融合新技术，代码简单易懂，组件拆分清晰，不做过度封装，符合常规开发模式，自动代码生成，修改简单高效，运行速度快。
- 使用Vue3的< script setup >语法糖，代码结构清晰，代码量大幅减少，真香！！！
- 界面简洁美观，使用 Ant Design of Vue 最新 3.x 版本，原汁原味，清晰明了，操作方便。
- 分支master后端直接对接 RuoYi-Vue 。[访问 RuoYi-Vue](https://gitee.com/y_project/RuoYi-Vue)
- 分支autoee-ui-for-ruoyi-vue-plus后端直接对接 RuoYi-Vue-Plus 最新版本 4.x。[访问 RuoYi-Vue-Plus](https://gitee.com/JavaLionLi/RuoYi-Vue-Plus)

> 具体内容请查看autoee-ui工程下的README.md

# RuoYi-pro-autoee：对RuoYi进行增强
## 增强内容

1. 在配置页面基本信息Tab中的备注字段上添加额外的配置信息（支持json格式）
> 备注配置内容说明：包括隐藏页面按钮、添加页面按钮、添加列表按钮、设置数据范围、关联主表信息、子表信息等等
2. 在字段信息配置页面增加配置项
> 如：只读、禁用、详细、必填、唯一、冻结列、级联、角色只读、表头样式、一级表头、二级表头等
3. 自动添加前后端扩展文件，避免增加字段后重新生成代码时手动修改内容被覆盖
4. 设置自动转码
5. BaseEntity 中新增加的参数
6. 增加内容管理模块
7. 优化上传控件生成的代码
8. 增加新增、修改、导入时的唯一校验
9. 增加部门权限数据过滤功能
10. 增加提交审核功能
11. 增加JWT登陆功能 ，可以适配前端APP
12. 增加生成业务模块通过jwt可以访问的controller

> 具体内容请查看RuoYi-pro-autoee工程下的README.md
