### 4. 依赖变更（pnpm）

## 四、本轮最后修复：菜单高亮（问题）

**现象**：暗黑模式下，点击菜单后叶子菜单项颜色没变化（激活文字白色与普通白色相同），反而父级目录（文件夹）整块变蓝底。

**根因**：`theme.scss` 暗黑下 `--menu-active-text: #ffffff` 与 `--menu-text: #fff` 无区分；`layout.scss` 的 `.el-sub-menu.has-active-child` 给父级目录强制加了蓝底。

**修复**：
- `theme.scss`：`html.dark { --menu-active-text: var(--el-color-primary) }`（激活菜单文字蓝色，与普通白色区分）。
- `layout.scss`：`.el-sub-menu.has-active-child > .el-sub-menu__title` 去掉 `background-color`，只保留蓝色文字。

（明亮模式无需改：`active-text-color` 走 Element Plus 默认主色蓝，正常。）

```powershell
node_modules\.bin\vite.cmd          # 端口 3000

# 后端登录拿 token（验证码禁用时可直取，用于 playwright 注入 localStorage）
Invoke-WebRequest http://localhost:8081/login -Method POST `
  -Body '{"username":"admin","password":"admin123"}' -ContentType application/json

# 浏览器注入 token（JSON 字符串方式，注意 Shell 双引号转义）
localStorage.setItem("Admin-Token", JSON.stringify("<token>"))

# 恢复验证码
# UPDATE ry-vue.sys_config SET config_value='true' WHERE config_key='sys.account.captchaEnabled';
# redis-cli DEL sys_config:sys.account.captchaEnabled
```
