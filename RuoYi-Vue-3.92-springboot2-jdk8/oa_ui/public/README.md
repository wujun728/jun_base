## 使用示例

### 代码示例
```bash
# 构建前端项目
npm run build:prod

# 构建产物输出到 public/ 目录
# 访问构建后的应用
http://localhost:8080/

# 使用 HTTP 服务器预览
cd public
python -m http.server 8000
# 或
npx serve .
```

### 调用方式
```bash
# 开发模式（热更新）
npm run dev

# 生产构建
npm run build:prod

# 查看构建产物
ls -la public/js/
ls -la public/css/
```

## 注意事项
1. **构建产物**: `public/` 目录是构建输出的产物，不要直接修改
2. **源代码修改**: 修改 `src/` 目录下的源代码后重新构建
3. **资源优化**: 构建时会自动压缩、分割代码、优化图片
4. **CDN 部署**: 生产环境可将 `public/` 目录部署到 CDN
5. **缓存清理**: 修改静态资源后需要清除浏览器缓存
6. **相对路径**: HTML 中使用相对路径引用资源
