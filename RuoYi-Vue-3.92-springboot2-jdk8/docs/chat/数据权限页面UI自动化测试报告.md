## 问题汇总

### 1. 【观察点】直接访问URL未登录时redirect异常
- **现象**：未登录状态直接访问 `http://localhost:9527/system/dataRule`，被重定向到 `/login?redirect=%2F404`，redirect参数为 `/404` 而非原始访问路径 `/system/dataRule`。
- **影响**：登录后不会自动跳回数据权限页面，而是跳到404页面。
- **建议**：路由守卫在捕获未授权访问时，应将原始目标URL作为redirect参数传递，而非fallback到/404。

### 2. 【观察点】首次加载"适用角色"列显示"-"
- **现象**：页面首次加载时，表格中"适用角色"列显示为"-"，但点击重置后显示为"普通角色"。
- **分析**：列表接口返回 `roleIds:"2"`，首次加载时角色名称解析可能存在时序问题或依赖角色接口未完成。
- **建议**：检查列表渲染时角色名称的解析逻辑，确保首次加载即可正确显示角色名称。

### 3. 【观察点】创建时间列无数据
- **现象**：表格"创建时间"列始终为空。
- **分析**：数据库 `sys_data_rule` 表中 `create_time` 字段为 `NULL`，接口返回 `createTime:null`。
- **建议**：检查新增数据权限时是否未写入 `create_time`，确认后端 `insert` 逻辑是否补充了创建时间。

### 4. 【观察点】页面Title缺少页面级标题
- **现象**：页面 `<title>` 为"CRMEB Java"，未包含当前页面"数据权限"信息。
- **建议**：可将页面Title动态设置为"数据权限 - CRMEB Java"以提升用户体验。

### 5. 【观察点】状态开关切换文案
- **现象**：开关从启用切换为禁用时，确认文案为 `确认要"停用""demo_tree_and_table"吗？`，引号嵌套较多。
- **建议**：优化文案格式，如改为 `确认要停用「demo_tree_and_table」吗？`，使用书名号或中文引号提升可读性。
